missing_number.py 
# Can you solve it?
def missing_num(nums):
    n = len(nums) + 1
    total = n * (n + 1) // 2
    return total - sum(nums)

# What will be the output for:
nums = [1, 2, 4, 5, 6]

❓ Challenge Question:

What integer value will the function missing_num([1, 2, 4, 5, 6]) return?

Target Array: [1, 2, 4, 5, 6]

Gauss Summation Formula: The sum of the first n natural numbers is given by n * (n + 1) / 2.

Here, since one number is missing from the sequential list of 6 numbers, n = len(nums) + 1 = 6.

Expected sum of numbers 1 to 6 = (6 * 7) / 2 = 21.

Actual sum of given elements = 1 + 2 + 4 + 5 + 6 = 18.

Difference = 21 - 18 = ?
