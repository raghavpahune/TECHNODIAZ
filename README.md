## 🌟 Key Features

1. **"Nature Meets Innovation" Handcrafted Thematic Design**:
   - Faithful recreation of the PBCOE CSE festival wall board with dark forest ambiance, organic ivy garlands, warm wooden frames with brass corner bolts, and glowing neon green/cyan circuitry.
2. **Interactive Cyber Tree of Knowledge**:
   - Centerpiece digital-botanical tree with interactive branches and domain nodes (`</>`, `AI`, `ML`, `C++`, `CLOUD SECURITY`, `DATA SCIENCE`, `WEB DEVELOPMENT`, `JS`, `IoT`, `CYBER COMPUTING`, `CYBER IoT`, `WIRELESS`).
3. **Dynamic Notice Board & Live Ticker**:
   - Real-time announcement ticker for breaking student alerts, urgent badge pulses, and complete notice history modal.
4. **Automated Live Tech News**:
   - Integrated technology API feed fetching real-time AI, Sustainable Computing, and Web breakthroughs with search, filters, and a "Scan for Live Tech News" QR badge.
5. **Daily Coding Challenge Arena**:
   - Exact Python puzzle from the reference wall board with interactive execution, hints, instant scoring, audio fanfare, and full-screen confetti celebration animation.
6. **Public Team Registration & Digital QR Pass System**:
   - No-login registration form with dynamic member roster and instant generation of a holographic digital entry pass with downloadable/printable QR codes.
7. **Secure Admin Verification Portal**:
   - Login-protected dashboard for the 4 core committee admins with a live browser-based camera QR code scanner, manual ID lookup, real-time analytics, CSV export, and live announcement broadcaster.
8. **Flagship Event Showcases & Agendas**:
   - Dedicated showcases for *IdeaStorm*, *TechCanvas*, *Mega College Quiz Quest*, *CodeRelay Hackathon*, and Sports Tournaments with full agendas for Sept 1st and Sept 2nd.

## 🚀 Running the Application Locally

### 1. Backend Server (Node.js + Express + MongoDB / Hybrid Storage Engine)
```bash
cd backend
npm install
npm start # or node server.js
```
*Backend runs on `http://localhost:5000`*

### 2. Frontend Application (Vite + React)
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on `http://localhost:5173`*
